# Wireshark Basics – IP Protocol Scan

## Description
This project focuses on basic Wireshark usage and filtering.
The objective of this task is to detect packets generated by an IP protocol scan
using the `nmap -sO` command.

## Environment
- OS: Kali Linux
- Tool: Wireshark (installed from official Kali repositories)

## Task 0: IP Protocol Scan
An IP protocol scan generates ICMP traffic as responses from the target.
The Wireshark display filter used allows detection of these packets.
