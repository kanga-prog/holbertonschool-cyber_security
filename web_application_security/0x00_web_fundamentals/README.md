# Web Application Security – Web Fundamentals (0x00)

## 📌 Description

Ce projet est une introduction pratique aux **fondamentaux du Web** et à la **sécurité des applications web**.  
Il met en place un environnement de test (lab) permettant de comprendre **comment fonctionne une application web**, comment le **frontend communique avec le backend**, et d’identifier les **vulnérabilités web courantes** dans une logique **Bug Bounty / Pentest**.

Le projet utilise un lab accessible via le domaine `web0x00.hbtn`, exposé uniquement lorsque le lab `cyber_websec_0x00` est lancé.

---

## 🎯 Objectifs pédagogiques

À la fin de ce projet, vous devez être capable d’expliquer **sans Google** :

- Comment fonctionne le Web
- Des exemples d’applications web
- Les différences entre Web 1.0, Web 2.0 et Web 3.0
- Les PWA (Progressive Web Applications)
- Comment le Frontend communique avec le Backend
- Stateful vs Stateless
- Données structurées vs non structurées
- Les principaux risques de sécurité des applications web
- Les Bug Bounty Programs

---

## 🧪 Environnement requis

- Kali Linux (ou Sandbox Holberton)
- Accès réseau Holberton (OpenVPN ou Sandbox)
- Navigateur web (Firefox recommandé)
- Terminal (curl, nmap, sqlmap)
